  Pour l'enregistrement correct des fichiers, veuillez utiliser la nomenclature suivante :
  
  -Le code d'un composant du robot doit être enregistré de cette manière : Nom du capteur/V(numéro de version)/V(numéro de la version).ino
  
  -Une modification/optimisation d'un fichier code d'une version V(numéro de la version) doit être enregistrée avec le nom : V(numéro de version).(numéro de l'itération du fichier).ino
  
  -Un ajout de fonction d'un fichier code doit ajouter 1 à sa version


Les noms des commits doivent porter la description des modifications faites.


L'organisation du projet se trouve dans l'onglet "Projects" de la repo.
